Font data from Adobe
====================

ZapfDingbats.afm is Adobe's font metrics file for ZapfDingbats, one of the 14 PDF Core Fonts, unmodified, from the
Core 14 AFM files Adobe published at http://partners.adobe.com/public/developer/font/index.html. Inkvolt PDF reads its
widths and glyph names to lay out text in ZapfDingbats when a PDF doesn't embed the font. The title, this paragraph and
the next one were added by Inkvolt's developers; the paragraph after them is Adobe's, unmodified.

zapfdingbats.txt is Adobe's ITC Zapf Dingbats Glyph List (https://github.com/adobe-type-tools/agl-aglfn), unmodified,
under the BSD-3-Clause licence in its own header. Inkvolt PDF reads it for the characters the glyph names stand for.
