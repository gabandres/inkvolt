# Inkvolt in Brazilian Portuguese (`pt-BR`): wording review

The voice and key terminology choices for Inkvolt Print and Inkvolt PDF in Brazilian Portuguese (`pt-BR`), across both Windows and macOS.

The voice is plain, natural Brazilian Portuguese using informal *você* (never *tu* and never European Portuguese vocabulary), sentence case for menus and buttons, and standard Windows/macOS pt-BR system names. Product, protocol and format names (`Inkvolt Print`, `Inkvolt PDF`, `Inkvolt Pro`, `AirPrint`, `Mopria`, `SNMP`, `IPP`, `PDF/A`, `OCR`, `GitHub`, `Ollama`, `LM Studio`) stay in English. Windows shortcut key names (`Del`, `Enter`, `Shift`, `Ctrl`, `Alt`, `Page Up`, `Page Down`, `Esc`, `Home`, `Tab`, `Backspace`) stay in English on Windows; macOS uses standard macOS pt-BR symbols/names.

## Language selection behavior

- Choosing **Same as Windows** / **Same as macOS** uses `pt-BR` only when the OS language is Brazilian Portuguese (`pt-BR`); European Portuguese (`pt-PT`) and generic `pt` fall back to English (`en`).
- Users on any system can explicitly pick **Português (Brasil)** in **Settings › Language** (or launch with `--lang pt-BR`).
