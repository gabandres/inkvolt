What's in This PDF comes to Inkvolt PDF for Mac.

- Tools › What's in This PDF… (also See What's in It… in Sanitize Document): one report of everything a PDF carries besides its pages: scripts and what they do, web addresses, files and programs it can reach, attachments, metadata, signatures, earlier versions, hidden layers and text, form values. Each item says whether Sanitize removes it. Save it as a web page or JSON. Nothing in the file is contacted.
- Edit Text & Images: clicking text on top of a picture edits the text.
- Redact by Pattern: a mistake in your own pattern is described in plain words.

For Macs with Apple silicon, macOS 15 or later. Signed with Developer ID and notarized by Apple. Free software under the GNU AGPL v3; source in this repository.
